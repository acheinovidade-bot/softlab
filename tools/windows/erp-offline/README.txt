ERP HÍBRIDO OFFLINE PARA WINDOWS

1. Mantenha o servidor do ERP acessível na primeira instalação.
2. Execute Install-ERP-Hibrido.cmd.
3. Se necessário, informe outra URL executando no PowerShell:
   .\Install-ERP-Hibrido.ps1 -Url "https://seu-erp.exemplo.com/?demo=pos"
4. Entre no PDV uma vez no modo online para armazenar catálogo, formas de pagamento e configurações.
5. Use o botão "Trabalhar offline" antes de desconectar. Se a internet cair, o PDV também entra no fluxo offline automaticamente.

As vendas offline permanecem no computador e sincronizam ao reativar "Trabalhar online".
